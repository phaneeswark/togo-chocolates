# TOGO Chocolates

Static website for TOGO Chocolates, inspired by Konaseema and East Godavari. The initial collection highlights milk and dark chocolate bars with nuts and berries.

## Editing

This is a buildless site. Edit `index.html`, `styles.css`, `script.js`, or the files in `assets/`, then push to `main`. GitHub Pages serves the repository root.

The product photographs are generated illustrations of the proposed products. Replace them with approved product photos before using them as a definitive catalog. Online checkout and business contact details have not been connected yet.

## Local preview

From this folder, run `python3 -m http.server 8765` and open `http://localhost:8765`.
