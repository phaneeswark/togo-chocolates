# TOGO Chocolates

Static website for TOGO Chocolates, inspired by Konaseema and East Godavari. The collection keeps the original milk and dark chocolate photography and includes packaging studies for Nuts, Berries, and Nuts & Berries in full and half sizes. The bar finder has client-side search, chocolate and addition filters, product detail panels, size selection, and a browser-local enquiry bag.

## Editing

This is a buildless site. Edit `index.html`, `styles.css`, `script.js`, or the files in `assets/`, then push to `main`. GitHub Pages serves the repository root.

The product photographs and packaging mockups are generated illustrations of proposed products. The packaging mockups include the word “Organic” as a design concept; the bars are not currently certified organic. Confirm certification and required labeling before using that claim on production packaging. Replace illustrative assets with approved product photos and print-ready artwork before using them as a definitive catalog. Online checkout and business contact details have not been connected yet. Enquiry selections are stored only in the visitor's browser.

## Local preview

From this folder, run `python3 -m http.server 8765` and open `http://localhost:8765`.
